
# E-commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales data to understand customer behavior, product performance, and sales trends.

## Tools Used
- **Python (pandas):** Data cleaning and transformation.
- **PostgreSQL / SQL:** Sales and customer analysis.
- **Power BI:** Interactive dashboard and data visualization.

## Project Workflow
1. Cleaned and prepared the dataset using Python.
2. Loaded the cleaned data into PostgreSQL.
3. Performed 11 SQL queries to analyze sales and customer behavior.
4. Created an interactive dashboard in Power BI.

## Dashboard
The dashboard presents revenue, orders, customer activity, delivery performance, and monthly sales trends.
